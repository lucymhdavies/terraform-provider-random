# random_failure (Resource)

The resource `random_failure` intentionally fails lifecycle operations based on configured percentages.

It can be used to test retry behavior and failure handling in Terraform configurations.

## Example Usage

```terraform
resource "random_failure" "example" {
  create_failure_percentage  = 25
  update_failure_percentage  = 10
  destroy_failure_percentage = 5
}
```

## Example Usage (Defaults)

```terraform
resource "random_failure" "example" {}
```

When all arguments are left unset, all percentages default to `0`, which means all operations always succeed.

### Optional

- `create_failure_percentage` (Number) Percentage chance that the create operation fails. Must be between `0` and `100`, inclusive. Default value is `0`.
- `destroy_failure_percentage` (Number) Percentage chance that the destroy operation fails. Must be between `0` and `100`, inclusive. Default value is `0`.
- `update_failure_percentage` (Number) Percentage chance that the update operation fails. Must be between `0` and `100`, inclusive. Default value is `0`.
